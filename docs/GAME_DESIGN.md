# 게임 전체 기획 (GAME_DESIGN)

- 버전: 1.0 / 2026-10-10
- 상태: 개발 전 **기획 기준안**
- 플랫폼: PC·모바일 웹, 싱글 플레이
- 장르: 방치형 + 미니게임 + 수집형
- 탐색 방식: **메뉴형 게임장**
- 그래픽: **모던 다크 UI + 콘텐츠별 2D 게임 그래픽**

## 1. 게임 개요

플레이어는 복합 게임장의 손님이자 아르바이트생이다. 아르바이트로 기본 자금을 벌고, 카드/주사위 등 미니게임으로 코인을 얻거나 잃는다. 2D 인형뽑기와 굿즈 가챠로 수집품을 얻고 도감을 완성한다. 경영 시뮬레이션과 게임장 소유 요소는 초기 범위에서 제외한다.

모든 게임머니는 **게임 속 가상 코인(C)**이다. 현금 입금·출금·환전·현금성 상품·실제 금전 보상이 없다.

## 2. 핵심 플레이 루프

1. 기본 방치형 알바 수익을 누적하거나 직접 알바 미니게임을 완료한다.
2. 획득한 코인으로 하이로우/주사위 등 베팅 미니게임에 도전한다.
3. 코인으로 인형뽑기와 굿즈 가챠를 진행한다.
4. 새 수집품을 도감에 등록하고 보유 수량 및 진척도를 확인한다.
5. 추가 게임, 알바와 가챠 시리즈가 생기면 확장 콘텐츠로 도전한다.

기본 자금이 소진돼도 무료 알바를 통해 언제든 회복할 수 있어야 한다.

## 3. 정보 구조

기본 메뉴는 네 개뿐이다.

| 메뉴 | 핵심 화면/행동 |
| --- | --- |
| 게임장 | 카테고리 필터, 미니게임 목록, 게임별 플레이 |
| 알바 | 방치 근무, 미수령 급여, 급여 수령, 직접 알바 |
| 뽑기 | 인형뽑기, 굿즈 시리즈/확률 확인, 가챠 진행 |
| 도감 | 수집 진척도, 필터, 수집품 상세, 보유 수량 |

상단 상태 표시줄에는 잔액, 알바 상태/미수령 수익(필요 시), 설정을 제공한다. 실행되지 않는 콘텐츠는 '준비 중'으로 명시하고, 실제 해금 기능이 있는 콘텐츠만 '잠김'으로 표시한다.

## 4. 아르바이트

- 방치형 기본 일자리: 게임장 카운터. 누적 급여는 명시적 '급여 수령'으로 공통 지갑에 지급한다.
- 앱이 닫혀 있는 동안의 계산도 지원하며 최대 4시간까지만 누적한다.
- 직접 알바 초기 유형: 물품 정리(단순 조작형). 실제 성공 판정 후 보수 지급, 재시도 대기 시간 적용.
- 장기 확장: 청소/재고 정리/기계 점검, 알바 숙련도 및 보수 상승.
- 수익 수치는 ECONOMY.md 참고.

## 5. 미니게임

공통 상태: 대기 → 베팅 확인 → 진행 → 결과 → 재도전.

공통 규칙: 코인 잔액/베팅 한도 확인, 베팅 시 재화 차감, 한 라운드의 결과를 **한 번만** 정산, 규칙과 확률(배당 포함) 확인, 재도전·돌아가기 지원.

### 하이로우 (1차)

공개된 카드보다 다음 카드의 숫자가 높은지/낮은지 선택. 동률은 베팅금 환불. 카드의 기준 값, 셔플/복원 방식, 유효한 시작 카드, 공개 카드별 성공 확률 및 배당 계산은 구현 전에 ECONOMY.md의 검증 항목에 따라 명확히 확정한다. 최초 버전은 **한 번 선택 → 결과** 한 라운드를 우선하며 연승/중간 정산은 확장 후보로 둔다.

### 주사위 (1차)

공정한 6면체 주사위 2개를 굴려 합계 홀/짝을 예측한다. 각각 성공 확률 50%. 구체 보상은 ECONOMY.md에 정의한다.

### 룰렛 (3차)

색상/숫자/구간 베팅 후보. 원판 구획과 규칙, 배당표, 결과 생성 및 애니메이션의 관계를 별도 설계 후 구현한다.

### 블랙잭 (3차)

플레이어 대 딜러. 히트/스탠드 기본 조작. 덱 수, 소프트17, 블랙잭 배당, 더블/스플릿 지원 여부를 추후 확정한다.

## 6. 인형뽑기 (2차)

버튼을 누르면 결과가 정해지는 단순 확률 가챠가 아닌 **실제 조작형 2D 크레인 게임**.

- 집게 좌우 이동 → 위치 선택 → 하강 → 집게 닫힘/인형 판정 → 상승/운반 → 배출구 획득 판정
- 집게와 인형 중심 간 거리, 인형 크기/상태와 집게 상태가 결과에 영향을 준다.
- 1회 이용료를 공통 지갑에서 차감하며 실패해도 이용료는 반환하지 않는다.
- PC(키보드/마우스)와 모바일(터치 컨트롤) 모두 지원.
- 획득 시 공통 컬렉션 시스템에 아이템을 추가한다.
- 충돌 및 집게 동작의 상세 알고리즘은 2차 착수 시 테스트 가능한 규칙으로 문서화한다.

## 7. 굿즈 가챠 (2차)

- 시리즈, 수집품 고유 ID, 타입, 희귀도, 가중치, 이미지와 확률을 데이터로 관리.
- 플레이 전에 개별 품목 확률 확인 가능.
- 중복은 추가 보유 수량으로 기록.
- 중복 교환 및 시리즈 완성 보상은 이후 확장 사항.
- 지급/차감은 하나의 결과 트랜잭션으로 관리해 새로고침 시 중복 지급을 방지한다.

## 8. 컬렉션/도감 (2차)

인형과 굿즈를 하나의 인벤토리/도감 스키마로 관리한다. 아이템 고유 ID, 유형, 시리즈, 희귀도, 이름, 보유 수량, 최초 획득일시와 도감 등록 여부를 구분한다. 전체/유형/시리즈/희귀도 필터와 획득·미획득 표시, 상세 패널, 시리즈 수집률을 제공한다.

## 9. 첫 플레이 경험

1. 첫 실행: 시작 코인 지급, 카운터 방치 알바 활성화.
2. 게임장: 하이로우/주사위 접근, 소액부터 베팅 가능.
3. 알바: 누적 급여 확인, 직접 알바 플레이 후 수령.
4. 2차 콘텐츠 추가 후: 인형/굿즈 수집, 도감 확인.
5. 재접속: 저장 상태 복원, 상한 적용된 미지급 방치 수익 확인.

가이드 문구는 필요한 조작·규칙·검증·상태에 한정한다. 불필요한 서비스 브랜딩/감성 문구는 만들지 않는다.

## 10. 우선순위 및 범위 관리

- 1차: 메뉴 UI + 공통 경제 + 저장 + 방치 알바 + 주사위 + 하이로우
- 2차: 2D 인형뽑기 + 굿즈 가챠 + 컬렉션/도감
- 3차: 룰렛 + 블랙잭 + 추가 알바 + 성장/해금
- 4차: 사운드/연출/성능/밸런스/데이터 안정성

상세 UI는 UI_SPEC.md, 금액·확률은 ECONOMY.md, 실제 개발 진행 여부는 ROADMAP.md를 단일 기준으로 사용한다.
