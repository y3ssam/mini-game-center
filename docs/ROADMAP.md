### 1차 완료 조건

게임을 다시 열어도 잔액과 알바가 보존되고, 주사위/하이로우에서 올바른 베팅과 정산이 일어나며, 320px 이상 모바일 화면에서 조작이 가려지지 않는다. 중복 정산·중복 오프라인 보수 테스트를 통과한다.

## 작업 규칙

개발 전 실제 파일과 의존성을 먼저 확인하고 요청과 관계없는 기능을 수정하지 않는다. 코드 수정 후 타입 검사, 빌드, 관련 테스트 결과를 기록한다. 테스트를 실행하지 못했다면 '미실행'으로 명시한다. 단계/항목의 완료 표시는 실제 구현과 검증 이후에만 갱신한다.
