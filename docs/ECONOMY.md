# 공통 경제 및 밸런스 (ECONOMY)

- 버전: 1.0 / 2026-10-10
- 상태: 초기 **임시 수치**. 구현 전/구현 중 밸런스 검증 필요.
- 재화: 단일 가상 코인(C). 현금 충전, 환전, 금전성 보상 없음.

| 신규 플레이어 시작 잔액 | 600 C |

## 2. 공통 지갑

- 잔액은 0 이상의 안전한 정수. 거래는 하나의 원자적 상태 갱신으로 처리한다.
- 잔액 부족/베팅 한도 초과/중복 요청이면 지급 또는 차감을 거부한다.
- 모든 변화는 명시적인 거래 유형(시작 지급, 알바 수령, 베팅, 게임 결과, 인형 이용료, 가챠 비용/보상)을 갖는다.
- 경제를 수정하는 유일한 진입점을 공유하고 미니게임/Phaser에서 잔액을 직접 변경하지 않는다.
- 각 라운드·급여 수령·가챠는 고유 작업 ID로 **중복 정산 방지**. 저장 중 실패/재시작에 대한 정책을 구현 전에 테스트로 확정한다.
- 베팅을 시작할 때 차감한 금액과 성공 시 지급되는 총액을 명확히 구분한다.

## 3. 방치 알바 수익

- 기본 주기는 5분마다 20 C, 4시간 기준 48주기 × 20 C = 960 C.
- 미수령 급여는 지갑과 구별된 값으로 관리.
- 재접속/수령 시 시간 계산의 기준 시각을 일관되게 갱신한다.
- 누적 시간은 4시간을 초과하지 않도록 계산한다. 이후에는 수령하기 전까지 추가 누적되지 않는다.
- 동일한 경과 시간에 대해 중복 급여를 만들지 않는다. 게임 실행 중 수익 업데이트와 오프라인 복귀 수익을 함께 검증한다.
- 시스템 시각이 뒤로 돌아가거나 저장 값이 손상된 경우 음수 수익이 생기지 않아야 한다.
- 수익을 수령한 뒤 남은 분 단위 경과 시간이 이중 계산되지 않도록 시각/잔여 시간을 분리해 관리한다.

## 4. 직접 알바

- 초기 1종 물품 정리. 성공 조건을 충족한 라운드마다 +60 C.
- 완료 즉시 지급. 재시도 대기 3분은 마지막 보상 지급 시각을 기준으로 적용.
- 빠른 반복 클릭, 새로고침, 여러 탭 경쟁 상태로 중복 지급하지 않는다.
- 난이도/보상은 실제 구현 후 플레이 시간과 방치 수익 대비 검증한다.

## 5. 주사위

- 공정한 6면체 주사위 2개, 합계 홀/짝 예측. 홀짝 각각 18/36 = 50%.
- 초기 지급 배당률: **1.9× (베팅액 포함 총 반환)**.
- 예) 100 C 베팅: 즉시 -100 C, 승리 시 +190 C → 순이익 +90 C; 패배 시 추가 지급 없음 → 순손실 -100 C.
- 20~200 C 정수 베팅, 배당 지급액의 소수점 처리 규칙은 일관되게 정의(해당 단위에서 소수 발생 시 버림을 기본안으로 고려).
- 수학적 기대 순수익: 0.5×(+0.9b) + 0.5×(-b) = -0.05b (b는 베팅액).
- 난수 생성은 테스트에서 의존성 주입이 가능하게 하고, 36개 결과 조합별 규칙을 테스트한다.

## 6. 하이로우

- 공개 카드 숫자를 기준으로 다음 카드가 높은지/낮은지 선택한다.
- **동률은 베팅액 전액 반환** (무승부).
- 시작 카드/다음 카드의 추출 규칙(복원 또는 비복원), 카드 숫자 범위(A=1, J=11, Q=12, K=13 여부), 성공 확률, 배당표는 코딩 시작 전 별도 결정해야 한다.
- 확률이 공개 카드에 따라 변하는 게임이므로 고정 1.9배를 임의로 적용하지 않는다.
- 배당 계산은 각 상황의 승리/동률/패배 확률을 반영하고, 화면에 최종 배당과 동률 처리 표시.
- 극단값 카드에서 승리 불가능한 방향은 선택할 수 없도록 한다.
- 초기 버전은 한 라운드 베팅 → 예측 → 결과/정산. 연승이나 중간 정산은 확장.

## 7. 기타 소비 시스템

- 인형뽑기: 150 C 이용료 선차감, 성공 판정은 조작/오브젝트 상태로 결정, 성공 시 인형 추가.
- 굿즈 가챠: 700 C 선차감, 수집품 지급. 시리즈·아이템별 확률합 100% 확인.
- 굿즈 가챠 희귀도 예시: 일반 70%, 레어 25%, 슈퍼 레어 5%. 각 개별 아이템 확률은 분배 기준을 시리즈 데이터에 지정한다.
- 수집품은 초기 버전에서 현금 또는 코인으로 판매할 수 없음. 중복 교환은 추후 기획.

## 8. 구현 및 검증 체크

- 초기 지급이 한 저장 데이터에서 정확히 한 번만 발생.
- 잔액 0/부족, 최대 베팅, 소수·음수·NaN/비정상 입력 검사.
- 수익/베팅/가챠 지급액 정산의 중복 호출 내구성.
- 시간 경계(0분, 4분 59초, 5분, 정확히 4시간, 그 이후), 앱 재시작, 여러 탭 동작 검증.
- 주사위 36개 조합의 모든 결과, 확률/지급액 수학적 검증.
- 하이로우 확률과 규칙/배당 확인 후 다양한 공개 카드 및 동률 시나리오 테스트.
- 가챠 시리즈별 확률 총합 100% 검증.
- 로컬 저장은 사용자 수정이 가능하므로 **부정행위 방지 보안 시스템으로 간주하지 않음**. 경쟁/계정 도입 시 서버 검증 별도 설계.
